
# 試しに

初めての人は難しいと思うので、テスト用のファイル領域を作っています。  
操作や流れに自身のない人はこちらを使っておさらいしよう。  

---

## タスク設定

仮にここで

> 「TestPage内の一番最後に今日の日付を記録する」

というタスクを考えます。  
IssueからAssigneeを設定するのは割愛しましょう。

---

## 手順

① Git: ブランチを確認する

  ターミナルで以下を実行します

  ```bash
  cd ~/Developer/mikan-sns
  git branch
  ```

  "*"のついているのが今いるブランチです。  
  mainでない場合は、

  ```bash
  git switch main
  ```

  を実行します。  

  ☆ 基本新しい作業はmainからスタートします。

② 最新版を取得する
  次に以下のコマンドで最新版を取得しましょう  

  ```bash
  git pull
  ```

  ☆ 他のメンバーの行った変更がある場合があるので、なるべく最新を保つ事が必要です。

③ ブランチを作る

  ```bash
  git switch -c test/add-date
  ```

  ☆ 他の人の行う開発から一度切り離します

④ VSCodeでTestPage.tsxを開く

  ☆ Feature-basedデザインを思い出しましょう。目的のファイルはどこにあるでしょう？

⑤ 変更を行う

  ☆ TSXファイルの構造を見て、return内の何処かに該当の変更を行います。（その日付を入れてみてください）

⑥ 保存し、確認する

  VSCode上で上書き保存をおこない、terminalに戻ります。  
  以下のコマンドで開発版のnodeアプリを自分のPC上で起動できます。

  ```bash
  npm run dev
  ```

  ブラウザ上で[http://localhost:3000/test](http://localhost:3000/test)を開くと変更がうまく行われたか確認できます

⑦ gitにコミットする

  変更をgitに記録します。

  ```bash
  git add .
  ```

  記録した変更内容を正式な変更履歴としてメッセージとともに登録します。
  メッセージは例えば、「ADD: 今日の日付を追加」などがいいでしょう。

  ```bash
  git commit -m "メッセージ"
  ```

  なお、この段階ではまだローカルPC上のブランチに登録されたに過ぎません

⑧ リモートにプッシュする

  ローカルPC上のブランチには変更が登録されています。これをリモートのgit リポジトリに反映します。

  ```bash
  git push origin test/add-date
  ```

  このコマンドは、test/add-dateブランチをリモートに反映する意味になります。  
  実際GitHub上より変更が行われているのが確認できるでしょう。
